# REFACTOR-BATCH-R70 —— 敌方技能混进「我方」时间表 + 一行的发动时刻放不下就往下撑

日期:2026-10-06。插件 **1.7.20 -> 1.7.21**;`5D0942C743CE95C6C9A3D08414383265465639A8FF1833DA7AE40782990C557F`(475,648 B)。
起因:用户打完一场(任务 9999,60.7 s)把 F4 页面截图发来,提两件事 ——
**①「发动时刻记录超过一行以后能不能把该表格行撑开多行显示」**;**②「你把敌方的技能也统计进来了并且没有进行敌我方区分」**。

**② 是真的,而且从 R66 起就一直是错的。** 本轮两件都做。

本轮**不移动任何伤害/归属数值、不改导出形状**(`contribution.schemaVersion` 仍 1.2)。

## 0. 一句话

- **只统计我方** —— R66 的文档一直写着「只有我方(`CharacterInfo.IsAlly`)」,但**三条路里只有 `skl` 真的过滤了**:
  `cmd`(自动技能命令钩子)与充能采样器**从来没有团队判断**。实测证据:那一场的导出
  `battle_9999_20261006_151957__B-…-001.json` 里 `actors[].team` 把 **ムスクーマ(key 8)** 与
  **ネフェスティス(key 9)** 都放在 **team 2(敌方)且没有 team 1 的同名个体**,而页面正是把这两行印在
  「我方」标题下面。对照:`skl` 那一路因为**有**这个判断,它的行里只有 team 1 的单位,SUM 还报
  `foreignSide=9`(敌方那 9 次奥义调用被丢掉)—— 这条对照就是根因的直接证明。
  修法:三路统一走一个判据 `SkillSidePolicy`(纯策略,`team == 1` = 我方,读不出来则**失败关闭**)与一个
  计数点 `SkillTimelineProbe.NoteForeign`;被丢掉的东西**计数 + 打证据行**,页面通道行现在追加
  `剔除非我方 N 条`。
- **一行的时刻放不下就往下撑** —— 首行仍然是 R66/R67 那一行(身份 + 9 个时刻 + 尾部),**续行只印时刻**,
  与首行的时刻列对齐,每行 14 个;最多 3 个续行 ⇒ 一行最多印 **51** 个发动时刻;再多时 `+N` 落在**最后一个续行的
  末格**(表意不变:还有 N 个没印出来)。实测那一场 マッドシーカー 的奥义 14 次发动:
  `1.5 6.2 10.6 15.0 19.5 23.9 28.3 32.8 37.2` / 续行 `41.6 46.1 50.5 54.9 59.4`,不再出现 `+6`。
- 行为用例 **1140 -> 1171**;变异负控 **175 -> 181**;源码 **104 -> 105 个 .cs / 28,138 行**。

## 1. 证据:敌方是怎么进来的

用户截图那一场(任务 9999 训练场,60.7 s,导出 `…151957…-001.json`,20 个 actor)里,同一批**角色名同时
出现在两个队伍**:

| 名字 | team 1(我方) | team 2(敌方) |
|---|---|---|
| ムスクーマ | — | **key 8** |
| ネフェスティス | — | **key 9** |
| レヴナント | key 6 | key 1 |
| T.O.W.E.R.typeR | key 7 | key 3 |
| ポポロット | key 5 | key 16 |
| [賢導]トレイラ | key 17 | key 18、key 20 |
| ソフィー | key 4 | key 19 |
| マッドシーカー / メルティエル | key 2 / key 11 | — |

- 导出的 `events[].atkTeam/vicTeam` 也印证同一套编号:`(1,2)` 525 次 = 我方命中敌方,`(2,1)` 571 次 =
  敌方命中我方。
- **页面(1.7.20)的行里有 ムスクーマ 与 ネフェスティス** —— 这两个名字在本场**只有 team 2**;
- 而**同场的 `skl` 通道行里没有它们**(`skl` 有 `CharacterInfo.IsAlly` 判断),它的 SUM 还报 `foreignSide=9`。
- 结论:漏的是 `cmd`(自动技能命令后缀)与**充能采样器**(`StandbyController.m_standbyDataList` 也不是「只有我方」)。
  因为同名角色两边都有,`cmd` 行的身份键是**文字身份**((单位名, 技能名, 种类)),敌方同名单位的发动会被**并进我方
  同一行**,于是既「统计进来了」又「看不出敌我」。

## 4. 覆盖不到的

1. **过滤器本身在探针里,不在 BehaviorTests 的编译清单里**(它需要 IL2CPP 面)。可执行的是**判据**
   (`policy/skill-side`)与**页面文本**(剔除数那一行);「三路都调用了这个判据」是代码事实,
   下一场实机由两个 SUM 的 `foreignSide=`/`foreign(cmd/skl/chg)=` 与页面上的 `剔除非我方 N 条` 复核。
2. 训练场 9999 的敌方与我方**同名**,这正是本轮能证明泄漏的原因;在普通任务里敌方名字通常不同,但过滤规则一样适用。
3. 续行的上限(3 行 = 51 个时刻)是**有意的**:再长就把整页让给一个单位。超过时 `+N` 仍然说明没印多少。
