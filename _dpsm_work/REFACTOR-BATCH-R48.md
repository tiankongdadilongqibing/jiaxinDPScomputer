# 重构批次记录 R48:用机器证明"搬走的是同一段代码"

> 第 46 轮把标签路由的扫描搬进 MasterDataAccess,当时的证据只是"人工逐行看过"。本轮把这件事**变成机器判定**,
> 并把它作为该次抽取的唯一离线证据(行为套件不含 MasterData/*,无法覆盖)。

## 0. 判据与结果

从 git 取**改动前**的 MasterDataNames.cs(db51ccc 的父提交),抽出原扫描主体;
从 MasterDataAccess.cs 抽出搬入后的主体;两边按**语句**规范化(压掉空白、去掉注释)后逐条比较,
并**显式排除**两类有意为之的差异:

1. 计数与提示行(_instErrors / _duplicateInstances / Note(label …))——设计上就留在调用方;
2. 新增的 info.Found = found.Length;——共享层把"看到几个实例"报告给调用方的唯一新增语句。

结果:**语句序列完全一致(IDENTICAL = True)**。也就是说,除了上面两类**有意**的差异,
搬走的是**逐条相同的代码**,没有任何隐性的改写。

## 1. 为什么这一步重要

- 行为套件覆盖不到 MasterData/*,所以"等价"只能靠**结构证据** + 将来的实机对照;
- "人工逐行看过"不是证据,机器比较才是:一旦有人在搬运时顺手改一个判断或顺序,这一步会立刻不通过;
- 它同时把"哪些差异是有意的"写成**可执行清单**(排除项),而不是散在注释里。

## 2. 边界(不夸大)

- 这只证明**扫描部分**是逐条搬移的,不证明**转储路由**与它行为一致(第 47 轮已证明它们不该合并);
- 真正的行为等价仍需"新构建跑一次 → 转储输出与 r42 基准逐字节一致",那需要一次部署决定。
