为什么换掉一个人之后总伤害变低了 —— 基于 1.5.2 实机导出的事后对账
生成时间:2026-10-03  分析对象:battle_411001_183213(旧队) vs 190954 / 191159(新队)
来源:全部数字都能用本目录 evidence_why_lower*.py 重算

=========================================================================================
0. 结论一句话
=========================================================================================
被你换掉的 メルティエル 身上带着一条【全队受益的“敌方易伤”规则】[海魔の残滓]:
「毒/火傷状態の敵全ての被ダメージがそれぞれ+15%」——它加的不是她自己的伤害,
而是【敌人承受的伤害】,所以队里每个人的数字都跟着掉。旧场 5516/5582 击都带着它,
新场 0 击。

但新队本身比旧队【更强】:把这条规则从旧场剥掉后,旧队只剩 155.0M,而新队实打 184.8M。
换句话说:换人让你【raw 输出 +19.2%】,但丢了价值约 +30% 的全队易伤,净 −8.6%。

1. 队伍变化
=========================================================================================
  旧 183213(11 个我方单位):... メルティエル(345击/8.24M)+ 火砲(65击/2.31M,召唤物)...
  新 191159(10 个我方单位):... ルゥ=ルルサ(1107击/11.92M)...

  * 出去的只有 メルティエル,以及她的召唤物 火砲(summon=True,随主人一起消失)。
    正好一个队伍栏位,与「换掉一个人」一致。
  * ルゥ=ルルサ 是 デバッファー,带 毒の短剣 / 時の砂時計。
  * 她自己那一份:出去 8.24M + 2.31M = 10.55M,进来 11.92M → 单项【+1.37M】,
    所以“换掉的人输出更低”不是原因。

3. 真因:被换掉的人带走的是一条“敌方易伤”全队规则
=========================================================================================
  在导出里检索规则文本:
    旧场:海魔の残滓 出现 11,346 次;comp2 注明它作用于 5,516 / 5,582 击
    新场:海魔の残滓 出现 0 次

  归属(导出 actors[].abilities[].name):
    旧场 actors[4] = メルティエル  ← 海魔の残滓
    旧场 actors[3] = マッドシーカー ← 母なる変異の飛沫(另一条同类规则,两场都在)
    新场:没有任何单位持有 海魔の残滓

  两条规则的文本(插件识别到的原文):
    [海魔の残滓]    毒/火傷状態の敵全ての被ダメージがそれぞれ+15%   ← 被换掉的人独有
    [母なる変異の飛沫] 毒/凍結/火傷状態の敵全ての被ダメージがそれぞれ+15%  ← 仍在队里

  它是“全局:敌方受伤”类规则,所以对【每一次我方命中】都乘一次 ——
  这才是“换一个人,全队都掉”的原因。

  规则生效率(旧场):敌人身上 毒 在 5122 击、火傷 在 5341 击、两者同时 4954 击
  (88%)。按插件模型“每个状态 ×1.15”,这条规则在旧场平均值 ×1.30。

  规则“在不在”的对照(本目录 evidence_why_lower6.py):
    只在旧场出现的规则文本:
      5,171 次  毒/火傷状態の敵全ての被ダメージがそれぞれ+15%(全局:敌方受伤)  ← 就是它
        314 次  同一条(状态×2)→×1.32
         25 次  同一条 →×1.15
        115 次  魔法与ダメージ+10%→×1.10(×2层)      ← メルティエル自己的攻击增益
         65 次  与ダメージ+30%(天赋数值)             ← 同上
    只在新场出现的规则文本:
          9 次  狂気 与伤害×1.50(狂気比150)

4. 把账算平
=========================================================================================
  用“按状态数 ×1.15^k”把这条规则从旧场剥离,得到“旧队若没有这条规则”的等效总量:

    旧队 实测                  202.2M   (其中 4919/5582 击是 毒+火傷 齐 → ×1.3225)
    旧队 剥离该规则后的等效      155.0M   (= 202.2M ÷ 1.15^k,落在 76.7%)
    新队 实测                  184.8M   (该规则 0 击)

  于是:
    新队 vs 旧队(都无该规则)  184.8 / 155.0 = 1.192   → 换人让 raw 输出 +19.2%
    该规则本身的价值          202.2 / 155.0 = 1.304   → +30.4%
    净                                     1.192/1.304 = 0.914 → −8.6%  ✔ 与实测吻合

  ⇒ 换人【没有】让你变弱,新队在同等条件下反而高 19%;
    你感觉“变低”是因为旧队有一条强度很高的全队易伤,新队没有等价替代。

  反向验算:若给新队补上同一条规则,新场会是 239.9M(实测 184.8M)— 也就是说这条规则
  在新场的敌人状态下值 ×1.30。

  ⚠ 诚实说明:上面“+19.2% / +30.4%”这个【拆分】依赖于插件对该规则的建模(每个
     毒/火傷状态各 ×1.15)。若游戏其实是“有该状态就 ×1.15 一次”而不是按状态数叠乘,
     那么拆分会变成大约 +4.6% / +14.5%。**净 −8.6% 是实测,不受影响**;受影响的只是
     把它归因给谁。这正是 P0 那个悬而未决的 ×1.15² 问题(见 HANDOFF §6 P0)。

5. 顺带发现的一个插件精度问题(与你的伤害无关,但必须修)
=========================================================================================
  新场里 BOSS 身上带着 狂気 的有 3,226 击(旧场几乎没有)。实测:
  在【敌人状态完全相同】时,有 狂気 的命中,游戏实伤 / 插件理论 ≈ ×1.5:

    敌人状态 毒+火傷+凍結:  无狂気 1.1418 (n=1977)   有狂気 1.6814 (n=1275)   ×1.47
    敌人状态 毒+火傷:       无狂気 1.1623 (n=690)    有狂気 1.7648 (n=939)    ×1.52
    敌人状态 毒:            无狂気 1.0627 (n=84)     有狂気 1.7097 (n=431)    ×1.61
    敌人状态 凍結+毒:       无狂気 1.0692 (n=128)    有狂気 1.6610 (n=455)    ×1.55

  未识别的差集中在 狂気 上,机制未查明(不编):插件只有 9 击读到了 狂気比150,
  而 calc.madnessRatio 在 2752/3226 个“敌人有狂気”的命中上是 None。

  后果:
    * 不会影响你看到的【实测总伤害】(那是游戏真实值);
    * 但会让插件的【理论伤害】偏低:新场 理论/基础 = 3.014,旧场 4.187;
      unexplained 从 1758 击涨到 4108 击,残余倍率出现大量 1.5 / 2.25 / 2.85。
    * 这也是新场 SUM(实伤/理论)=1.3709、旧场 1.1116 的原因。
