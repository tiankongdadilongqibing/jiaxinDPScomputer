## 1. 为什么"两个半边都要"值得写成 `Valid`

`Valid = Calc != null && At >= 0.0` **不是装饰**:1.5.0 的缺陷正是"上一场的 calc 标注了这一场的命中"——
引用活着,但没有任何东西给它重新盖时间戳。读取方若只检查 `Calc != null`,就等于重新打开那个缺陷。
所以容器把"两个半边"写成一条可测试的规则,并用例把三种组合分别钉住:

| 组合 | Valid |
|---|---|
| calc + 真实戳 | ✅ |
| calc 为 null + 有戳 | ❌(用例名直接指向 1.5.0) |
| calc + 哨兵 `-1` | ❌ |
| calc + 戳 `0.0` | ✅(**0 是真实的战斗时钟读数**,不是"没有") |
